# AI-Powered Debt Collection Agent Simulator

An AI-powered debt collection simulator built using Gemini and Gradio.

## Features

* Conversational debt collection agent
* Structured payment intent extraction
* Payment commitment analysis
* Customer risk classification (Low/Medium/High)
* Deployed on Hugging Face Spaces

## Tech Stack

* Python
* Gemini API
* Gradio
* Hugging Face Spaces
